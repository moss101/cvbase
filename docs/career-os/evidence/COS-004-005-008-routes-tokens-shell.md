# COS-004 / COS-005 / COS-008 — Route contracts, semantic tokens and the six-space shell

20–21 September 2026 · Verified locally: `npm run typecheck`, `npx vitest run`, `npm run build`, `node scripts/generate-theme-css.mjs`, and a live browser session against the local Supabase stack (real passwordless sign-in through Mailpit, real QA account with legacy data).

## COS-004 — Canonical route contracts and compatibility parsing

* `components/NavigationProvider.tsx`: `Route = LegacyRoute | CareerRoute`. `CareerRoute { view:'career', space, sub?, id?, section?, context?, query? }`. Grammar implements every IA ledger family (`/app/today`, `/app/career[/sub]`, `/app/career/goals/:id`, `/app/opportunities[/:id]?view=`, `/app/campaigns[/:id]?view=`, `/app/applications[/:id[/:section]]`, `/app/coach[/:id]`, `/app/library[?type=]`, `/app/library/{templates|tailor|ats}`, `/app/library/cvs/new`, `/app/library/cvs/:id/edit`, `/app/library/documents/:id`, `/app/search`, `/app/notifications`, `/app/settings[/integrations]`). Ids are validated (`ID_PATTERN`); an invalid path id → `not-found`, an invalid hint is dropped; only `view`/`type` filters and the four context keys survive; fixed query order.
* Legacy routes unchanged (`/app`, `/app/<tab>`, `/builder[/:id]`, `/resources`, `/pricing`, `/legal[/tab]`, `/sign-in?next=`). `/app/settings`, `/app/billing`, `/app/admin` are KEEP rows and still parse as dashboard tabs until cutover. Unknown `/app/...` → owned-context-safe `not-found`; unknown top-level → landing. `?next=` continuation round-trips nested routes.
* Builders `careerPath.*`, ledger `LEGACY_TO_CAREER`, fallback `legacyTabForSpace`. `vercel.json` gained an `/app/(.*)` rewrite because the catch-all skipped dotted ids.
* App.tsx: `case 'career'` → flag `null` spinner, `false` legacy Dashboard under the same URL, `true` lazy `CareerShell`. Enabled cohort: legacy dashboard tabs `replace` into their ledger destinations (smart-studio deliberately stays legacy until COS-041).
* Tests: `components/common/__tests__/navigationRoutes.test.ts` — 21 tests (legacy exactness, every family, sections, filters, hints, invalid ids, not-found, round-trip of 26 routes, sign-in continuation, builders, ledger).
* Live: `/app/resumes` → `/app/library?type=cv` (observed via `window.location`); `/app/applications/not-a-real-id/cv?opportunity=x` rendered the Applications space with the honest placeholder (no other record opened); malformed id now short-circuits to NotFound in the repositories (UUID guard).

## COS-005 — Semantic tokens and shared primitives

* `scripts/generate-theme-css.mjs`: `SEMANTIC` alias layer (`surface-canvas/panel/elevated`, `text-primary/secondary/muted`, `border-default/strong`, `action-primary/secondary`, `status-success/warning/danger/info`, `focus-ring`, `evidence-verified/confirmed/inferred/incomplete`) emitted as `--ct-sem-*` / `--cb-sem-*`; 48 new contrast gates (181/181 checks pass in both themes). Tailwind mapping: `bg-surface-*`, `text-content-*`, `border-border-default|strong`, `bg/text-action-*`, `bg/text-status-*`, `ring-focus-ring`, `text/bg-evidence-*`. Existing classes unaffected (build verified). CV templates and the marketing palette untouched.
* Deliberate token picks: `text-muted` → slate-500 (ink-faint is 3.55:1), `text-secondary` → slate-600, `status-info` → secondary-dark, `border-strong` → slate-500 light / slate-400 dark, `focus-ring` uses primary's text value so it is visible on the dark canvas.
* Primitives (`components/careeros/primitives/`): Button, Pill/StatusChip, Skeleton/SkeletonCard, StatePanel (loading|empty|error|offline|denied|ai-unavailable|partial with status/alert roles), EvidenceBadge (four labelled states, icon + text), ActionCard, FitBreakdown (two labelled regions, counts, insufficient data, stale), ReadinessChecklist (no percentage), ContextSwitcher (buttons, conflicts), ActivityTimeline, SpaceHeader, EntityCard + DocumentCard/OpportunityCard/CampaignCard/ApplicationCard/CareerGoalCard/AchievementCard. All strings via `t('careeros.*', default)`.
* Tests: `components/careeros/__tests__/primitives.test.tsx` (18) and `flags.test.ts` (5).

## COS-008 — Six-space shell (desktop and mobile)

* `components/careeros/CareerShell.tsx`, `shell/CareerOsProvider.tsx`, `shell/spaces.ts`, `shell/DesktopSidebar.tsx`, `shell/MobileNav.tsx`, `data/useOwnedQuery.ts`, `spaces/*` (lazy chunks per space).
* Desktop: six spaces (Today, Career, Opportunities, Campaigns, Coach, Library), utilities (Search, Inbox), tools (Applications, Template gallery, PRISM Tailor, ATS Checker, Resume), account (Profile, Settings, Billing, Career resources, Admin when admin). Mobile: Today, Opportunities, Coach, Campaigns, More (Career, Library, utilities, tools, account); pushed detail screens use the existing MobileTopBar back arrow; native back handling is the existing NavigationProvider stack + BottomSheet back interception.
* Shell renders without AI. The provider ensures the `career_profiles` row and runs the idempotent legacy backfill (`career_os_migrate_user`) once (`migration_version < 1`), shows an honest partial-state banner on failure with retry, resolves the route's owned context through `careerContext.resolveContext`, rewrites contradicting query hints to the authoritative relation, clears caches on account switch, and counts unread inbox items.
* Signed-out shell shows a denied panel with sign-in; the CV editor route (`/app/library/cvs/*`) renders `ResumeBuilder` full-screen with back to the Library.
* Live evidence (local stack, QA account `careeros-qa@example.com` seeded with a primary resume + wishlist/applied/interview tracker rows): sign-in via emailed code → `/app/today` opened the shell; `career_profiles.migration_version = 1`; three legacy rows projected to opportunities (wishlist → `saved`, applied/interview → `applied`) with `legacy_application_id` kept; 10 candidate facts (`inferred`/`candidate`) plus the `profile_field` current title as `user_confirmed`. Screenshot recorded in the session; no console errors on a clean load after the UUID guard.
